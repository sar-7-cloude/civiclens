      Data setup

      Load the built-in sample dataset, or upload your own anonymised CSV.

      Expected CSV format

      Header row required. Columns (case-insensitive):

      • complaint text (or text, description) — required
      • category — required (roads, streetlights, water, sanitation, drainage, encroachment, noise, other)
      • ward — required
      • date — required (YYYY-MM-DD or DD/MM/YYYY)
      • status — required (open, in-progress, resolved)
      • optional: resolved date, urgency (low/moderate/high), sentiment, id

      Use anonymised data only — no names, phone numbers or addresses of individuals.
